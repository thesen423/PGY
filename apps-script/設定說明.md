# PGY 排課雲端設定說明

完成後：
- **管理頁** `pgy.html`：登入管理密碼後，所有修改自動存到 Google 試算表，多台電腦可共用。
- **查詢頁** `pgy-view.html`：學生、導師可直接開啟查看（課程月曆／學生查詢／導師專區）。

整個設定大約 10 分鐘，只需要做一次。

---

## 步驟 1：建立 Google 試算表

1. 到 Google 雲端硬碟，新增一個空白試算表，例如命名為「PGY 臨床技能排課資料」。
   - 建議**不要**用原本報名表的試算表，兩者分開比較安全。
2. 上方選單 **擴充功能 → Apps Script**，會開啟程式編輯器。

## 步驟 2：貼上程式碼

1. 把編輯器裡原本的 `function myFunction() {}` 全部刪除。
2. 開啟本資料夾的 `Code.gs`，**全部複製**後貼上。
3. 按 💾 儲存。

## 步驟 3：設定密碼（不要寫在程式碼裡）

1. 左側齒輪 **專案設定**，捲到最下方 **指令碼屬性 → 新增指令碼屬性**。
2. 新增：

| 屬性 | 值 | 說明 |
|---|---|---|
| `ADMIN_PW` | 自訂的管理密碼 | **必填**。管理頁登入雲端用 |
| `TEACHER_PW` | 自訂的導師密碼 | 選填。有設定的話，導師查詢時需要輸入；沒設定則導師只要輸入姓名 |

3. 按「儲存指令碼屬性」。

> 密碼放在指令碼屬性，不會出現在 GitHub 上公開的檔案中。

## 步驟 4：部署成網頁應用程式

1. 右上角 **部署 → 新增部署作業**。
2. 齒輪選 **網頁應用程式**。
3. 設定：
   - 說明：PGY 排課
   - 執行身分：**我**
   - 具有存取權的使用者：**所有人**
4. 按「部署」，第一次會要求授權：選你的帳號 → 「進階」→「前往（不安全）」→「允許」。
5. 複製產生的 **網頁應用程式網址**（`https://script.google.com/macros/s/.../exec`）。

## 步驟 5：把網址填進網站

編輯 repo 根目錄的 `pgy-config.js`，把網址貼到 `api` 的引號中：

```js
window.PGY_CONFIG = {
  api: "https://script.google.com/macros/s/xxxxxxxx/exec",
  contact: "教學部聯絡人　分機 #57427"
};
```

提交到 `main` 分支，GitHub Pages 約 1 分鐘後更新。

## 步驟 6：第一次上傳資料

1. 用**原本整理資料的那台電腦**開啟 `pgy.html`（本機資料存在這台電腦的瀏覽器）。
2. 按右上角「☁ 未登入雲端」，輸入管理密碼 → 「登入並同步」。
3. 雲端是空的，會自動把本機資料上傳。回到試算表，會看到「梯次、學員、課程、訓練紀錄」等工作表。
4. 之後換電腦，只要開啟 `pgy.html` 登入雲端，就會下載同一份資料。

## 分享給學生與導師

- 查詢頁網址：`https://<你的 GitHub 帳號>.github.io/<repo 名稱>/pgy-view.html`
- 可直接分享特定分頁：
  - 課程月曆：`…/pgy-view.html#cal`
  - 學生查詢：`…/pgy-view.html#student`
  - 導師專區：`…/pgy-view.html#teacher`

### 個資保護
- **課程月曆**只顯示課程、日期時間、地點，不顯示任何學員。
- **學生查詢**必須輸入人事號，只回傳本人資料，姓名中間以 ○ 遮蔽。
- **導師專區**只顯示該導師負責、已送確認的梯次與學員姓名（不顯示人事號）；草擬中的梯次不會出現。
- 完整名單只存在試算表與管理頁（需管理密碼）。

### 導師確認流程
1. 管理頁預排後，把梯次設為「待導師確認」（或按「草擬 → 送導師確認」），並填好導師姓名。
2. 導師到查詢頁「導師專區」輸入**與排課表相同的姓名**（「醫師／老師」等稱謂可加可不加）。
3. 導師按「✓ 時間可以」或「✗ 無法，建議改期」。回覆會記錄在試算表「導師回覆」工作表。
4. 管理頁按「↻ 檢查導師回覆」（或「立即同步」），系統自動更新梯次狀態；建議改期的梯次可在編輯畫面一鍵採用建議時間。

## 常見問題

**Q：修改了 Code.gs 之後要怎麼更新？**
部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署。網址不變，不用改 `pgy-config.js`。

**Q：出現「雲端與本機資料不一致」？**
代表這台電腦有未上傳的修改，但雲端也被其他電腦更新過。不確定時先到「匯入／備份」匯出本機備份，再選「使用雲端版本」。

**Q：可以兩個人同時編輯嗎？**
可以，但建議同一時間只由一人修改。若發生衝突，系統會提示選擇保留哪一份，不會默默覆蓋。

**Q：管理密碼忘了／要換？**
到 Apps Script 專案設定的指令碼屬性修改 `ADMIN_PW` 即可，立即生效。

**Q：查詢頁顯示「查詢系統尚未啟用」？**
`pgy-config.js` 的 `api` 還是空的，或尚未提交到 `main`。
